Cómo se calcula

  • Cobertura del código JavaScript: líneas de JavaScript que están en archivos .js analizados por Snyk Code, divididas entre todas las líneas de JavaScript del proyecto (incluido el que está incrustado en <script> dentro de HTML). Es la cifra importante, porque ahí está la lógica que puede tener vulnerabilidades.
  • Archivos de código cubiertos: archivos analizados por algún producto de Snyk, divididos entre todos los archivos de código no excluidos. Los scripts .bat/.sh, la configuración YAML, el plan de JMeter y el CSS no son tipos que Snyk Code analice.
  • ℹ No aplica: tipos de archivo que Snyk Code no analiza por diseño (no son código de la aplicación). No es un fallo de seguridad ni de cobertura.
  • Excluidos (.snyk): rendimiento/resultados/**, node_modules/**.
